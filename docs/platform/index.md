# ☁️ AdminService.Cloud Platform

> 📝 **Documentation in development.** The platform is under active development — this section will
> grow as features stabilize. In the meantime, the [CLI documentation](/cli/) covers everything that
> already works today, since `asc-daemon` is fully usable standalone, without the platform.

## What's coming

The platform sits on top of `asc-daemon` and will add a web UI, multi-node management, and team
features. Planned documentation topics:

- 🔐 Access control & permissions
- 🤖 AI assistant
- 🧬 App cloning
- 🛍️ App store
- 🎨 Appearance
- 💾 Backup policies & schedules
- 💳 Billing
- 🌐 Domains & SSL
- 🌱 Environments
- 🌍 Internationalization
- ⚖️ Load balancer
- 📰 Public pages
- 🎛️ UI modes
- ⚙️ User settings
- 🖧 Node service
- 📣 Notifications & Telegram
- 💵 Payments
- ✅ Task manager
