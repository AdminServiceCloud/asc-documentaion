# 🔁 asc autoupdate

Manage auto-updates. Proxies to `asc-updater auto ...`.

## Usage

```
asc autoupdate <enable|disable|status>
```

- **`enable`** — turn auto-updates on.
- **`disable`** — turn auto-updates off.
- **`status`** — show the current auto-update setting.
