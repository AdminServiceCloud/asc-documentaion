# 📋 asc status

Показывает версию демона, состояние сервиса и сводку по установленным
приложениям.

## Использование

```
asc status
```

Без флагов и аргументов. Быстрая одноразовая проверка состояния — объединяет
то, что `asc service status` и `asc app list` показали бы по отдельности.
