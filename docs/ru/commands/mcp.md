# 🤖 asc mcp

Открыть локальный ASC daemon как сервер Model Context Protocol.

## Использование

```
asc mcp serve
```

### serve

Запускает MCP через стандартные ввод и вывод. Нужен запущенный daemon.
Доступ определяется UID процесса: обычный пользователь управляет только
своими приложениями, root — всеми.

Настройка клиента и правила безопасности — в [🤖 MCP-сервере](/ru/cli/mcp-server).
