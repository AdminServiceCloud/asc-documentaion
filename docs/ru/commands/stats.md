# 📊 asc stats

Показывает потребление CPU, памяти, дискового пространства и I/O, а также
сетевого I/O по приложениям, аналог `docker stats --no-stream`. Показывает
ваши приложения; под `sudo` — все, сгруппированные по владельцу.

NET I/O и DISK I/O — накопительные суммы байт с момента запуска приложения
(«rx / tx» и «read / write»), а не скорость — та же конвенция, что и в
одноимённых колонках `docker stats`. Сетевой I/O доступен только для
Docker-приложений — у них своё сетевое пространство имён; systemd- и
process-приложения делят его с хостом, поэтому для них колонка показывает
прочерк.

## Использование

```
asc stats [--sort cpu|mem] [--live]
```

## Опции

- **`--sort <cpu|mem>`** — сортировка строк по потреблению. По умолчанию: `cpu`.
- **`--live`** — обновлять на месте до прерывания (Ctrl+C), как обычный
  `docker stats` (без `--no-stream`).
