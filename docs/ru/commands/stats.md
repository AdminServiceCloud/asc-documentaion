# 📊 asc stats

Показывает потребление CPU, памяти и диска по приложениям, аналог
`docker stats --no-stream`. Показывает ваши приложения; под `sudo` — все,
сгруппированные по владельцу.

## Использование

```
asc stats [--sort cpu|mem] [--live]
```

## Опции

- **`--sort <cpu|mem>`** — сортировка строк по потреблению. По умолчанию: `cpu`.
- **`--live`** — обновлять на месте до прерывания (Ctrl+C), как обычный
  `docker stats` (без `--no-stream`).
