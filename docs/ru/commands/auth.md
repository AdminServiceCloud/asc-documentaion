# 🔑 asc auth

Управление git-авторизацией для приватных репозиториев пакетов.

## Использование

```
asc auth <действие>
```

### add

```
asc auth add <target> [--type repo|registry] [--token <token>] [--ssh-key [<путь>]] [--username <user>] [--app <id>]
```

Сохранить учётные данные для git-хоста или реестра образов (напр.
`github.com/myorg`, `ghcr.io/myorg`).

- **`target`** — хост, host/prefix, URL репозитория или image-референс (позиционный, обязателен).
- **`--type <repo|registry>`** — что авторизует credential. По умолчанию: `repo`.
- **`--token <token>`** — токен доступа (https-репозитории и реестры).
- **`--ssh-key [<путь>]`** — SSH-ключ для `git@`/`ssh` репозиториев; без пути —
  интерактивный выбор из `~/.ssh`.
- **`--username <user>`** — имя пользователя, обязательно для реестров образов вместе с токеном.
- **`--app <id>`** — использовать credential только для одного приложения (его uuid или id из `asc ls`).

### list

Список настроенных credential'ов (только типы и методы, никогда не секреты).

### remove

```
asc auth remove <target> [--type repo|registry]
```

Удалить credential для хоста или префикса.

- **`--type <repo|registry>`** — удалить только этот тип; по умолчанию удаляются
  все типы, подходящие под паттерн.
