# 🔁 asc autoupdate

Управление автообновлениями. Проксирует в `asc-updater auto ...`.

## Использование

```
asc autoupdate <enable|disable|status>
```

- **`enable`** — включить автообновления.
- **`disable`** — выключить автообновления.
- **`status`** — показать текущую настройку автообновлений.
