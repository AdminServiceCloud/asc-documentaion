# 💾 asc backup

Создание, восстановление и управление бекапами приложений.

## Использование

```
asc backup <действие> [аргументы]
```

### create

```
asc backup create <app> [--storage <имя>]...
```

Забекапить приложение: репозиторий, конфиг и данные, минус исключения
`asc.backup.yaml`.

- **`--storage <имя>`** — хранилище для бекапа, можно повторять; по умолчанию
  политика бекапов приложения (`asc app settings`), иначе просто `local`.

### restore

```
asc backup restore <app> <backup> [--storage <имя>]
```

Восстановить приложение из бекапа — **приложение должно быть остановлено**
(деструктивно: заменяет репозиторий, конфиг и данные приложения).

- **`backup`** — имя бекапа, как показывает `asc backup list`.
- **`--storage <имя>`** — хранилище, где лежит бекап. По умолчанию: `local`.

### list

```
asc backup list <app> [--storage <имя>]
```

Список бекапов приложения на одном хранилище, от старых к новым.

- **`--storage <имя>`** — хранилище для листинга. По умолчанию: `local`.

### prune

```
asc backup prune <app> [--storage <имя>] --keep <n>
```

Удалить самые старые бекапы приложения на одном хранилище сверх `--keep`.

- **`--storage <имя>`** — хранилище для очистки. По умолчанию: `local`.
- **`--keep <n>`** — сколько бекапов оставить (обязателен).

### storage add

```
asc backup storage add <имя> --type local|s3|ftp|sftp [флаги...]
```

Добавить хранилище бекапов. Обязательные флаги зависят от `--type`:

- **`local`**: `--dir <путь>`
- **`s3`**: `--bucket <имя> --region <регион> [--endpoint <url>] --access-key <ключ> --secret-key <секрет> [--prefix <префикс>]`
- **`ftp`/`sftp`**: `--host <хост> [--port <порт>] --user <пользователь> [--password <пароль>] [--dir <путь>] [--key <путь>]` (`--key` — только для SFTP, вместо `--password`)

### storage list

Список настроенных хранилищ (`local` есть всегда, не отображается).

### storage remove

```
asc backup storage remove <имя>
```

Удалить настроенное хранилище (`local` удалить нельзя).
