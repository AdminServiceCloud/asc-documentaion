# 💽 asc disk

Показывает использование диска — сокращённая версия
[`asc app disk`](/ru/commands/app#disk) (root видит приложения всех пользователей).

## Использование

```
asc disk
```

Полоска суммарного места, занятого приложениями, относительно ёмкости
файловой системы хранилища, затем использование каждого приложения, по убыванию.
