# 🧰 asc service

Управление systemd-юнитом сервиса демона.

## Использование

```
asc service <действие>
```

### install

Установить юнит сервиса и включить автозапуск. Создаёт systemd-юнит
(запускающий `asc serve`) и включает его — с этого момента демон стартует при
загрузке системы.

### uninstall

Остановить, отключить и удалить юнит сервиса.

### start

Запустить сервис.

### stop

Остановить сервис.

### restart

Перезапустить сервис.

### status

Показать состояние сервиса (active / inactive / not installed). То же самое,
что и часть вывода `asc status`, вместе с версией и сводкой по приложениям.
