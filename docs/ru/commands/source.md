# 🗂️ asc source

Управление источниками реестров: своим списком; под `sudo` — общим системным
списком для всех пользователей.

## Использование

```
asc source <действие>
```

### add

```
asc source add <url> [--name <имя>]
```

Добавить источник реестра (`https://` или `file://`).

- **`url`** — URL источника (позиционный, обязателен).
- **`--name <имя>`** — имя источника; выводится из URL, если не задано.

### remove

```
asc source remove <имя>
```

Удалить источник по имени.

### list

Список настроенных источников.
