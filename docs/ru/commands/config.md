# ⚙️ asc config

Управление конфигурацией демона (`config.toml`).

## Использование

```
asc config <действие>
```

### lang

```
asc config lang [en|ru]
```

Показать или задать язык вывода CLI. Без аргумента — печатает текущую
настройку; с `en`/`ru` — задаёт её, влияет на вывод всех команд (включая эту
подпись "Больше информации") через систему переводов.

### debug

```
asc config debug [on|off]
```

Показать или задать debug-логирование. Без аргумента — печатает текущую
настройку; с `on`/`off` — задаёт её, сохраняется в `[log] level` в `config.toml`
(`RUST_LOG` по-прежнему имеет приоритет в рантайме).
