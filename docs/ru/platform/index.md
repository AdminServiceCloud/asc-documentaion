# ☁️ Платформа AdminService.Cloud

> 📝 **Документация в разработке.** Платформа активно разрабатывается — этот раздел будет расти по
> мере стабилизации функций. А пока полностью актуальна [документация CLI](/ru/cli/) — `asc-daemon`
> полноценно работает автономно, без платформы.

## Что появится

Платформа надстраивается над `asc-daemon` и добавит веб-интерфейс, управление несколькими нодами и
командную работу. Планируемые темы документации:

- 🔐 Права доступа
- 🤖 AI-ассистент
- 🧬 Клонирование приложений
- 🛍️ Магазин приложений
- 🎨 Внешний вид
- 💾 Политики и расписания бекапов
- 💳 Биллинг
- 🌐 Домены и SSL
- 🌱 Окружения
- 🌍 Интернационализация
- ⚖️ Балансировщик нагрузки
- 📰 Публичные страницы
- 🎛️ Режимы интерфейса
- ⚙️ Настройки пользователя
- 🖧 Node service
- 📣 Уведомления и Telegram
- 💵 Платежи
- ✅ Менеджер задач
