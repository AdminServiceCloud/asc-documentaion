# 🤖 MCP

## 📌 Описание

ASC открывает локальный daemon через
[Model Context Protocol](https://modelcontextprotocol.io/). MCP-клиент может
получать сведения о приложениях и логи, а также выполнять те же операции ASC,
которые доступны через CLI.

## 🎯 Подключение клиента

Daemon должен быть запущен, а `asc` — доступен в PATH клиента. Настройте
stdio MCP-клиент на запуск сервера командой `asc mcp serve`:

```json
{
  "mcp_servers": {
    "asc": { "command": "asc", "args": ["mcp", "serve"] }
  }
}
```

Для Claude Code:

```bash
claude mcp add asc -- asc mcp serve
```

Сервер использует UID процесса MCP, полученный от операционной системы.
Обычный пользователь получает доступ только к своим приложениям, root — ко
всем. Повышайте права только при действительной необходимости.

## 🏗️ Возможности и безопасность

MCP предоставляет инструменты только для чтения состояния системы, метрик,
сведений о приложениях, логов, настроек и бекапов. Также доступны операции
установки, обновления, управления, настройки, создания, восстановления и
удаления приложений.

Daemon авторизует каждую ссылку на приложение. Разрушительные операции
помечены для MCP-клиента, чтобы он мог запросить подтверждение. Команды хоста
выполняются от пользователя, который запустил `asc mcp serve`, а не от daemon.

Полный список инструментов, устранение проблем подключения и сведения о
безопасности смотрите в [документации MCP-сервера daemon](/ru/cli/mcp-server).
Синтаксис команды — в [asc mcp](/ru/commands/mcp).
